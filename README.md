## ✨ Overview

Welcome to the **Terminal Number Guessing Game**! This is a classic console-based game where you test your intuition against the computer. The rules are simple, but can you find the secret number in the fewest attempts possible? 

Built purely in C++, this project is a fun, lightweight demonstration of control flow, loops, random number generation, and user input handling in the terminal.

---

## 🎮 How to Play

1. **The Setup:** The computer secretly picks a random integer between **1 and 100**.
2. **The Guess:** Type your guess into the terminal and hit enter.
3. **The Feedback:** 
   * 📈 If your guess is **too high**, the game will prompt you to go lower.
   * 📉 If your guess is **too low**, the game will prompt you to go higher.
4. **Victory:** Once you hit the exact number, the game celebrates your win and displays your **total attempt count**!
